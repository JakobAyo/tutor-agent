# Goals

> **Responsibility:** Measurable outcomes that define success (e.g. concepts mastered, ability to explain or review agent code).

1. **No missed concepts:** every worth-knowing concept a Claude Code agent uses in my sessions lands in my concept memory.
2. **Understanding from real code:** for any concept in the memory I can open a lesson that explains it using the code where it appeared, then generalizes it.
3. **A growing `understood` list:** progress is the number of concepts I've marked `understood` over time.
4. **Explain the agent's work:** on demand, the tutor explains what the agent just did and *why*.

Long-term aim: reach senior-SWE-level understanding faster, so I can explain and review the code my agents write.
