# Problem

> **Responsibility:** The pain this project solves: generating code with agents without learning anything from it.

I studied CS and know the fundamentals in theory, but I have little practical experience. My coding agents constantly use concepts I can't fully explain: design patterns, architecture choices, tooling, infrastructure. They work across web (TS/React/Node), Python and AI agents, backend and infra, and systems code.

When the agent writes the code, the work gets done but I don't learn from it. Over time I ship code I can't explain or review, and I become a "vibe coder" instead of an engineer.

Missing piece: something that notices the concepts the agent uses that are new to me and helps me understand them, at the moment they show up in real code.
