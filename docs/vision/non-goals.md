# Non-Goals

> **Responsibility:** What the tutor deliberately will NOT do (e.g. write code for me).

- **No code writing.** The tutor explains. It never writes or changes code in my projects.
- **No interrupting the agent.** It never blocks, slows down, or injects anything into the observed Claude Code session ([0007](../decisions/0007-interaction-model.md)).
- **No syntax tutoring.** Basics like `for` loops or variable assignment are out of scope ([triggers](../observation/triggers.md)).
- **No quizzes or spaced repetition for now** ([0006](../decisions/0006-drop-socratic-quizzes-for-now.md)).
- **No agents other than Claude Code for now** ([0002](../decisions/0002-observe-claude-code-only.md)).
- **No separate API billing.** It runs on my subscription only ([0003](../decisions/0003-claude-p-subscription-runtime.md)).
