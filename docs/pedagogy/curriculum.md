# Curriculum

> **Responsibility:** The map of concepts from junior to senior level and the order to learn them in.

There is **no fixed curriculum** for now. The curriculum emerges from what my agents actually use: the concept memory *is* the curriculum.

Concept categories, used to group concepts in the tutor pane:
- Design patterns
- Architecture and system design
- Language mechanisms (Python, TS, Rust/Go/C, ...)
- Testing
- Tooling and build systems
- Infrastructure and deployment (Docker, CI, databases)
- Concurrency and performance
- AI/LLM engineering (agents, prompting, tool use)

Open question: a later version could suggest prerequisites, for example "learn X before Y".
