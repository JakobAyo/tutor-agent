# Assessment

> **Responsibility:** How understanding is checked (quizzes, exercises, code critiques) and scored.

For now there is **no tutor-run assessment** ([0006](../decisions/0006-drop-socratic-quizzes-for-now.md)).

- Understanding is **self-assessed**: I mark a concept `understood` in the tutor pane.
- The tutor never sets `understood` itself.
- Known weakness: self-assessment can be over-optimistic. If that becomes a problem, add optional "quiz me" checks through a new ADR.
